\paragraph{TL;DR.} On the regression, nearest-neighbor and descriptive-statistics cases run through every program, DiGiTerra 0.1.0 agreed with a plain scikit-learn script to the precision each program prints, and R, Excel, Orange and Altair AI Studio agreed with the same script within a relative difference of $10^{-6}$. A review that set out to break the application reproduced 25 defects, and each fix has a regression test. Among eleven other no-code tools, DiGiTerra is the one that writes a run record with the input hash and package versions and signs its saved models. DiGiTerra does not join tables, filter rows by formula or read databases, and the node-graph tools do. Every desktop tool compared is free, and the cloud tools bill by the hour.
