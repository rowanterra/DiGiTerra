Tooltips reachable on this step (help button label -> text):
  What is the mode? -> Guided fills every setting with a default and shows only the four steps. Full opens every setting the training route accepts, in the same steps. The choice is remembered in this browser.
  What is the step list? -> The four steps. A step opens when the one before it is done; any opened step can be revisited.
  What is the task? -> Classification predicts a class label. Regression predicts a number. Clustering groups rows without a target. The page proposes one from the target column; change it if the proposal is wrong.
  What is Model? -> The estimator to fit, from scikit-learn. The Guided default is a random forest, which needs little tuning. Every model in the list is trained through the same route.
  What is the hyperparameter table? -> The parameters of the chosen estimator, read from scikit-learn itself. A blank keeps the default shown. A value typed here reaches the estimator and is recorded in the run manifest.
  What is n_neighbors? -> How many nearest rows vote for a prediction. Small values follow the training rows closely.
  What is weights? -> uniform gives every neighbour one vote; distance gives nearer neighbours more.
  What is algorithm? -> Parameter algorithm of KNeighborsClassifier; the scikit-learn default is shown.
  What is leaf_size? -> Parameter leaf_size of KNeighborsClassifier; the scikit-learn default is shown.
  What is p? -> Power of the Minkowski distance: 1 is Manhattan, 2 is Euclidean.
  What is metric? -> The distance measure between rows.
  What is metric_params? -> Parameter metric_params of KNeighborsClassifier; the scikit-learn default is shown.
  What is n_jobs? -> CPU cores to use; blank means one.
  What is Split method? -> How rows are divided into training and test halves. Random is the usual choice. Time-ordered keeps the latest rows for the test. Grouped keeps every row of a group on one side, for data where several rows come from one site or sample.
  What is Split column (time or group)? -> The column a time-ordered or grouped split reads. Not used by the random split.
  What is Test fraction? -> The fraction of rows held out as the test set. 0.20 keeps one row in five for testing.
  What is Stratify the random split by a column? -> Keeps the class mix of the chosen column the same in both halves of a random split. Off unless a column is chosen.
  What is Scaler? -> Rescales the predictors before fitting. Trees do not need it; distance and linear models often do. Standard centres to mean zero and unit variance; min-max maps to 0 to 1; robust uses the median and quartiles; quantile maps to a uniform distribution.
  What is Rows with blanks? -> What to do with rows that have a blank in a modeling column: remove them, or fill the blank with the column mean, median or mode computed on the training rows only.
  What is Zeros? -> What to do with zeros in the modeling columns, for data where zero means "not measured": keep them, remove the rows, or fill them with the mean or median.
  What is Random seed? -> The random seed. The same seed and settings give the same split and the same fit. It is written to the run record.
  What is Decimal places in the results? -> Decimal places shown for the metrics. The predictions file is always written at full precision.
  What is Feature selection? -> Keeps a subset of predictors before fitting: the k with the strongest univariate score, recursive elimination, or the ones a model weights. The chosen columns are named in the result.
  What is k for selection? -> How many predictors to keep when feature selection is on.
  What is Outlier method? -> Finds and removes outlying training rows before fitting, by interquartile range, z-score, an isolation forest or the local outlier factor. The count removed is reported.
  What is Cross-validation? -> Cross-validation on the training rows, reported beside the single test score. Stratified K-fold keeps the class mix in every fold.
  What is Folds? -> How many folds the cross-validation uses.
  What is Hyperparameter search? -> Searches over hyperparameter values with cross-validation and keeps the best set. Randomized tries a sample of combinations; grid tries all of them. The chosen values are written to the run record.
  What is Fit the model? -> Fits the model with the settings on this page. A blocking data check stops the run and says why.

Tooltips reachable on this step (help button label -> text):
  What is the mode? -> Guided fills every setting with a default and shows only the four steps. Full opens every setting the training route accepts, in the same steps. The choice is remembered in this browser.
  What is the step list? -> The four steps. A step opens when the one before it is done; any opened step can be revisited.
  What is the task? -> Classification predicts a class label. Regression predicts a number. Clustering groups rows without a target. The page proposes one from the target column; change it if the proposal is wrong.
  What is Model? -> The estimator to fit, from scikit-learn. The Guided default is a random forest, which needs little tuning. Every model in the list is trained through the same route.
  What is the hyperparameter table? -> The parameters of the chosen estimator, read from scikit-learn itself. A blank keeps the default shown. A value typed here reaches the estimator and is recorded in the run manifest.
  What is n_neighbors? -> How many nearest rows vote for a prediction. Small values follow the training rows closely.
  What is weights? -> uniform gives every neighbour one vote; distance gives nearer neighbours more.
  What is algorithm? -> Parameter algorithm of KNeighborsClassifier; the scikit-learn default is shown.
  What is leaf_size? -> Parameter leaf_size of KNeighborsClassifier; the scikit-learn default is shown.
  What is p? -> Power of the Minkowski distance: 1 is Manhattan, 2 is Euclidean.
  What is metric? -> The distance measure between rows.
  What is metric_params? -> Parameter metric_params of KNeighborsClassifier; the scikit-learn default is shown.
  What is n_jobs? -> CPU cores to use; blank means one.
  What is Split method? -> How rows are divided into training and test halves. Random is the usual choice. Time-ordered keeps the latest rows for the test. Grouped keeps every row of a group on one side, for data where several rows come from one site or sample.
  What is Split column (time or group)? -> The column a time-ordered or grouped split reads. Not used by the random split.
  What is Test fraction? -> The fraction of rows held out as the test set. 0.20 keeps one row in five for testing.
  What is Stratify the random split by a column? -> Keeps the class mix of the chosen column the same in both halves of a random split. Off unless a column is chosen.
  What is Scaler? -> Rescales the predictors before fitting. Trees do not need it; distance and linear models often do. Standard centres to mean zero and unit variance; min-max maps to 0 to 1; robust uses the median and quartiles; quantile maps to a uniform distribution.
  What is Rows with blanks? -> What to do with rows that have a blank in a modeling column: remove them, or fill the blank with the column mean, median or mode computed on the training rows only.
  What is Zeros? -> What to do with zeros in the modeling columns, for data where zero means "not measured": keep them, remove the rows, or fill them with the mean or median.
  What is Random seed? -> The random seed. The same seed and settings give the same split and the same fit. It is written to the run record.
  What is Decimal places in the results? -> Decimal places shown for the metrics. The predictions file is always written at full precision.
  What is Feature selection? -> Keeps a subset of predictors before fitting: the k with the strongest univariate score, recursive elimination, or the ones a model weights. The chosen columns are named in the result.
  What is k for selection? -> How many predictors to keep when feature selection is on.
  What is Outlier method? -> Finds and removes outlying training rows before fitting, by interquartile range, z-score, an isolation forest or the local outlier factor. The count removed is reported.
  What is Cross-validation? -> Cross-validation on the training rows, reported beside the single test score. Stratified K-fold keeps the class mix in every fold.
  What is Folds? -> How many folds the cross-validation uses.
  What is Hyperparameter search? -> Searches over hyperparameter values with cross-validation and keeps the best set. Randomized tries a sample of combinations; grid tries all of them. The chosen values are written to the run record.
  What is Fit the model? -> Fits the model with the settings on this page. A blocking data check stops the run and says why.
