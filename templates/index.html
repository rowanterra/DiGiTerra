About DiGiTerra

DiGiTerra is a browser tool for exploring a tabular dataset, training a model on the dataset, and reviewing the results.

The interface says Model throughout. The documentation and the code say estimator in one place, and the two mean different things. An estimator is the registry entry a person selects. A model is what exists after that estimator is fitted to data.

A run moves through the five pages in the figure: upload, data exploration, model preprocessing, modeling, and inference on new data. The rail on the left of every page after upload lists them in that order.

Disclaimer. DiGiTerra is an exploration tool, not a production system. Results from the application are not claimed to be reliable for decision making. Findings should be checked with a statistician for model assumptions, performance in context, and interpretation. The tool supports expert analysis and does not replace the analysis.

Tutorial

This tutorial trains one classifier on examples/penguins.csv, a file that ships with DiGiTerra. It holds 344 rows of Palmer penguin measurements in 7 columns. The target is the species. Two columns hold text and eleven rows have a missing value, so the run uses one-hot encoding, missing-value handling and a stratified split.

You can load this file without leaving the app. Click Try an Example on the welcome screen.

The columns

A is species, the target. B is island, text. C to F are the measurements. G is sex, text.

1. Load the file

Click Try an Example on the welcome screen.

The page lists the seven columns. The rail appears on the left. The Data panel reads Tabular, 344 × 7.

2. Look at the data

Click Data Exploration in the rail. Click Correlation Matrix.

The heat map covers the four numeric columns. Flipper length and body mass correlate most. The text columns do not appear, because a correlation needs numbers.

3. Handle the missing values

Click Model Preprocessing in the rail. Click Run autodetect under Data Cleaning.

The check reports blanks in five columns. sex has 11 and each measurement column has 2.

Tick All numeric under Missing values. Set Action for blanks to Remove rows with blanks.

4. Transform the text columns

Set Are any columns non-numeric? to Yes, or click Run autodetect beside it.

DiGiTerra names island and sex. A transform makes one indicator column for each value they hold.

5. Choose the columns and the split

Set Modeling Task Type to Classification. Enter B-G in Indicator Columns. Enter A in Target Columns.

Set Stratify the model's splitting by a specific variable? to Yes, and stratify by the target.

The classes are uneven: 152, 124 and 68. A stratified split holds those proportions in the training rows and the test rows, so the smallest class is not left out of one of them.

Click Process Configurations and Continue.

6. Train the model

Select Simple Modeling. Click Random Forest Classifier in the Models panel. Click Run This Model.

The five-step strip moves to Run and then to Results. The result gives an accuracy near 0.99 on the test rows, a confusion matrix over the three species, and a comparison with the baseline. The baseline predicts Adelie every time and reaches about 0.44, so the model earns its place. The exact numbers move with the seed.

7. Predict on new rows

Click Inference on New Data in the rail. Upload a file with the same six indicator columns.

The page shows one predicted species for each row.

8. Watch a data check stop a run

A data check refuses a run whose result would mislead. This step causes one on purpose.

Open examples/penguins.csv in a spreadsheet. Copy column A into a new column at the end. Name the new column leak. Save the file under a new name.

Upload the new file. Set the task type to Classification. Enter B-H in Indicator Columns and A in Target Columns. Continue, select a model, and run it.

The run stops. The page reads: DiGiTerra stopped the run. The data checks found a problem that makes the result misleading. Every value of 'leak' maps to exactly one class of 'species'. The column is the target in another form. Remove the column, then train again.

The message is correct. A column that copies the target predicts it perfectly, and a score from that column says nothing about new data. Remove the column and run the model again.

The desktop build allows a run past a data check. Open Advanced, then Data Checks, and give a reason. A served installation does not allow it unless the operator turns it on. A run that skips a check is recorded as not valid for decision use.

File Format and Column Entry
Accepted files

DiGiTerra reads .csv, .xlsx, .xlsm, and .parquet. An Excel workbook contributes its first sheet.

Column letters

Columns are selected by spreadsheet letter. A range is written A-D, and selections are separated by commas, as in A-D, F, H.

Targets vs indicators

Indicators are the input columns, such as geochemical or environmental measurements. Targets are the columns to predict, such as species or concentration.

Modeling Types

DiGiTerra supports three task types.

Regression (32 estimators) Classification (23 estimators) Clustering (12 estimators)
Target A continuous numeric column, such as concentration or yield. A categorical column, such as species or sample type. Two classes or more. None. Rows are grouped by similarity of the indicator values.
Fits The relation between the indicators and the target, then predicts the target for new rows. A rule that assigns each row to one of the classes in the target column. Groups of rows that resemble one another.
Reports R², MSE, RMSE, MAE; predicted against actual; residuals. Accuracy, precision, recall, F1; ROC curves; confusion matrix. Silhouette, Calinski-Harabasz, Davies-Bouldin; labels on PCA axes; labels to CSV.

Not included

DiGiTerra fits tabular models only. Time series forecasting has no ARIMA or sequence model; a regression on lagged columns is the available substitute. Deep learning stops at the multilayer perceptron, so there is no CNN, RNN, or transformer architecture (the preprocessing transformers that encode text columns are unrelated and are included). Reinforcement learning and recommendation systems are not included. The outlier step removes or caps training rows with Isolation Forest or LOF; it is not an anomaly detector for new data.

Modeling Approaches

The registry holds 67 trainable estimators: 32 for regression, 23 for classification and 12 for clustering. Every mode offers all of them for its task, so the rail catalog reads 32, 23 or 12 with the task type. tests/unit/test_catalog_reachable.py reads the sweep record and fails when an estimator trains but no select offers it.

Regression and classification offer three modeling modes after Model Preprocessing. The modes are independent, and clustering has one interface with no mode selection.

AutoML selects and tunes the model without manual configuration. It chooses the estimator (or takes the one named), selects features by recursive feature elimination, removes outliers with Isolation Forest, tunes hyperparameters by randomized search, and scores by cross-validation.

Simple Modeling fits one chosen estimator with its main hyperparameters and reports the score against a baseline.

Advanced Modeling keeps every Simple setting and adds feature selection, outlier handling, hyperparameter optimization, and cross-validation, each set by hand.

Feature Selection

Feature selection keeps a subset of the indicator columns.

Select K Best Filter Method

Keeps the K columns with the highest F-test score against the target.

Recursive Feature Elimination (RFE) Wrapper Method

Fits an estimator, removes the lowest-ranked columns, and repeats until the requested count remains. Slower than Select K Best.

Select From Model Model-based

Keeps the columns whose importance or coefficient in a fitted estimator exceeds a threshold.

Outlier Handling

Outlier handling removes or caps extreme rows in the training data.

Interquartile Range (IQR)

Marks values below Q1 minus 1.5 IQR or above Q3 plus 1.5 IQR.

Z-Score (3σ rule)

Marks values more than 3 standard deviations from the mean.

Isolation Forest

Scores each row by the depth needed to isolate the row in random trees.

Local Outlier Factor (LOF)

Compares the local density of each row with the density of the neighbors of the row.

Marked rows are then either removed from the training data or capped, which clips the marked values to the threshold.

Hyperparameter Search

The search replaces the manual hyperparameter values.

Grid Search

Fits every combination in the grid, so it is the slowest of the three.

Randomized Search

Fits a fixed number of combinations sampled from the grid.

Bayesian Optimization

Selects each next combination from a probabilistic model of the scores, so it reaches a good setting in the fewest fits. Requires an extra dependency.

Warning: Search time grows with the model, row count, grid size, and fold count. Grid search is the slowest.

Glossary

RMSE is Root Mean Square Error. It measures the differences between true or predicted values

MAE is Mean Absolute Error. Absolute error is the magnitude of the difference between the prediction and the observation's value. MAE is the average absolute error values for a set of predictions and observations. It measures the magnitude of errors for the group.

A MAE or RMSE of 0 is a perfect prediction so lower scores are better but vary depending on the values in the dataset
